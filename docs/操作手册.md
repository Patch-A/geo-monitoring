# GEO Monitoring Toolkit — 操作手册

## 一、依赖与环境

- Python 3.9+（标准库为主）
- `pip install playwright`（浏览器采样用；走系统 Chrome，无需 `playwright install`）
- DeepSeek API key（可选，仅 API 通道需要）：`$env:DEEPSEEK_API_KEY='sk-xxx'`

## 二、首次准备（一次性）

1. **启动专用 Chrome**：双击 `scripts/启动_调试Chrome_EN.bat`
   - 端口 9222，独立 profile `.geo-chrome-profile`（登录态隔离，不影响日常浏览器）
   - 首次运行会自动检查端口占用与调试接口可用性
2. **登录 5 个引擎**（各一次）：
   - 豆包 doubao.com / 文心一言 yiyan.baidu.com / Kimi kimi.moonshot.cn / 通义 tongyi.aliyun.com / 元宝 yuanbao.tencent.com
3. 确认 `templates/GEO采样_问题集.csv`（60 问）存在

## 三、采样

### DeepSeek API（自动）
```powershell
python scripts/geosample_deepseek.py --limit 6    # 试跑
python scripts/geosample_deepseek.py --resume     # 全量（断点续跑）
```

### 浏览器（5 引擎）
```powershell
# 按引擎逐个跑；引擎 key: doubao / yiyan / tongyi / yuanbao / kimi
python scripts/geo_sample_browser.py --engine doubao --limit 3
python scripts/geo_sample_browser.py --engine kimi --ids A7,D5 --resume   # 精确补跑
python scripts/geo_sample_browser.py --engine tongyi --group B            # 按组
```

### 人工采样（可选）
复制 `templates/GEO采样_基线记录_模板.csv` → 命名 `GEO采样_基线记录_<日期>.csv` → 逐条填写。

## 四、分析

```powershell
python scripts/geoanalyze.py --only 豆包,DeepSeek   # 指定引擎
python scripts/geoanalyze.py                        # 全部
```

## 五、位次回填（豆包）

对提及 [EXPO] 的回答人工判定推荐位次，写入 `GEO采样_位次回填_<日期>.csv`：
```csv
qid,rank
A1,4
B5,1
```
再跑 geoanalyze 生效（TOP3 = rank 1-3）。

## 六、整合 + 报告

```powershell
python scripts/integrate_data.py     # 300 行整合 CSV
python scripts/generate_report.py    # HTML 报告
```

## 七、常见问题

| 问题 | 处理 |
|---|---|
| Profile 冲突 | 关掉占用的 Chrome（见 SKILL.md 4.4） |
| Kimi 限流 | 分批跑 + 批间休息；回答带提示行不判无效 |
| 验证码频繁 | 按组跑、手动过验证 |
| 回答只抓到追问句 | 重跑（join_all 已修复多块拼接） |
| 新引擎适配 | `--debug` dump DOM → 精调选择器 |
