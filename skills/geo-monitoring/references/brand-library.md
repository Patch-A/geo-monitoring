# 品牌实体配置（Brand Entity Configuration）

> 本文是**模板**：把要监测的品牌/展会信息填入下表，替换脚本 `scripts/` 中的识别词表，
> 即可用于任何品牌/展会的 GEO 监测。原仓库不包含任何具体品牌信息。

## 1. 填写你的品牌实体

| 字段 | 填写说明 | 示例 |
|---|---|---|
| 实体中文全称 | 监测对象的标准中文名 | 你的展会中文全称 |
| 实体英文全称 | 标准英文名 | YOUR EXPO FULL NAME |
| 主办方 | 主办主体 | 主办方名称 |
| Slogan/定位句 | 一句话定位 | "你的定位句" |
| 关键档期 | 时间/地点/届数 | 2026 年 X 月 X 日，城市·展馆 |
| 认证/背书 | UFI 等认证 | 认证情况 |
| 官方落地页 | 官网 URL | https://example.com |

## 2. 更新脚本识别词表

在 `scripts/geoanalyze.py` 与 `scripts/generate_report.py` 中替换：

```python
# 目标实体变体（品牌名 + 简称 + 股票代码/英文名）
BRAND_VARIANTS = ["你的品牌名", "简称", "英文名", ...]      # 目标实体
SPONSOR_VARIANTS = ["主办方名", "简称", "股票代码", ...]    # 主办方/背书实体
COMPETITORS = ["竞品展会1", "竞品展会2", ...]              # 竞争实体（仅内部研判）
```

## 3. 采样分析口径

- 提及率 = 回答中出现目标实体变体的提问数 / 总提问数
- TOP3 推荐率 = 目标实体进入推荐位前 3 的提问数 / 提及数
- 竞争实体仅统计频次，写作内容不点名竞品

## 4. 注意事项

- 变体词表尽量全（品牌名/简称/英文名/错别字变体），保证识别准确
- 关键词：目标词要有可验证的事实块（时间/地点/主办方/规模），便于 AI 引用
- 若监测多市场（如南北两站），在问题集中分维度覆盖
