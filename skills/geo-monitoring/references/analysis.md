# 分析详解（Analysis）

## geoanalyze.py

输入：同目录下 `GEO采样_基线记录_*.csv`（人工）、`GEO采样_api快照_*.csv`（DeepSeek）、`GEO采样_浏览器_*.csv`（浏览器）。

处理：
1. 全部加载 → 按 (引擎, 问题编号) 去重取回答最长一条
2. 合并 `GEO采样_位次回填_*.csv` 的人工位次（rank）
3. 统计：提及率 / TOP3 率 / 按核心词 / 引用域名 Top15 / 竞争实体频次 / 准确性问题 / 位次待判定清单

输出：`GEO采样_基线报告_YYYYMMDD.md` + `GEO采样_合并明细_YYYYMMDD.csv`

## 位次回填（人工）

对「提及 [EXPO] 但 rank 为空」的回答，逐条判断 [EXPO] 在推荐列表的名次：
- rank=1：第一个被推荐的展会
- rank=2/3：依此类推
- 未进前五：填 >5 的值（如 6）

写入 `GEO采样_位次回填_YYYYMMDD.csv`（列：qid, rank），再跑 geoanalyze 生效。

## 有效性判定（is_quality_answer）

回答被认定为有效需满足：长度 ≥100、非纯追问句、非限流话术、非「只有思考过程」文本。
限流话术：Kimi 有点累了 / 聊的人太多了 / 换个话题再聊聊 / 算力不足（占比>60% 才判）等。
思考阶段特征：搜索网页 / 思考已完成 / 用户询问 / 让我搜索 等（且无展会实体标志）。

## integrate_data.py

按 (引擎, 问题编号) 去重取最长 → `GEO采样_5引擎整合_YYYYMMDD.csv`（5 引擎 × 60 问 = 300 行），供分发/贴表。

## generate_report.py

读取整合数据 + 位次回填 → `GEO多引擎对比报告_YYYYMMDD.html`：
- 摘要卡片（总提及率/[BRAND]提及/位次数/TOP3）
- 各引擎总览表
- 核心词 × 引擎热力矩阵
- 竞争格局 Top20
- 豆包位次分布
- 结论与建议
